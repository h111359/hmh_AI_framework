DESC: Normative for question format when quiz or examine the user

FORMAT:
1. Question title: Short question name
2. Question text: One or several sentencies explaining the task
3. Options: minimum 2 and maximum 7 options
4. Instruction: note to the user to choose one answer

EXAMPLE:

```markdown
**Question: Capital of Bulgaria**

 What is the name of the capital of Bulgaria?

A) Veliko Tarnovo
B) Bulgaria City
C) Sofia
D) Serdika
E) Balkan

Choose one
```

RULES:
MUST: Title in bold
MUST: Keep empty line between Question title and Question text
MUST: Keep empty line between Question text and Options
MUST: Each option in a single line
MUST: No empty lines between options
MUST: One emtpy line after the last option
